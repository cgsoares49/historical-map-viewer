Commands & Help
Vibe Map voice/text commands
show/go [place] — navigate to a place
show [place] at [year] — navigate + set date
date [year] — set the date (e.g. "date 100 BCE")
zoom [N] — set zoom to specific value (e.g. "zoom 7")
zoom in/out [N] — zoom N steps (default 1)
center [lon] [lat] — set center (e.g. "center 13 42")
home — reset to default view
world — show world context view
toggle/show/hide [layer] — coasts, borders, dots, grid, labels, water
run forward / backward — start animation
stop — stop animation
speed [N] — set seconds per year (e.g. "speed 2")
step [N] — set years per step (e.g. "step 10")
pan [dir] — pan N/S/E/W/NE/NW/SE/SW
info [place] — show info popup for a place
dismiss — close info popup
Years: "100 BCE", "-100", "1648 CE", "1648"
Map interactions
Drag — pan the map; re-renders on release
Scroll wheel — zoom in/out centered on cursor
Double-click — zoom in centered on click point
Shift+click — selection rectangle; drag to reposition; Display or Enter to render
Right-click — country info popup
Alt+click — distance measurer (click twice for measurement)
Escape — cancel distance or selection mode
